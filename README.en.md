# MarvelComics

> 🇧🇷 [Leia em Português](README.md)

This prototype was developed for the Android challenge of the Google Developers Group (GDG-ABC/SP).
The goal was to create, in just one week, an Android application that would consume the public Marvel API and work as a comic book catalog, displaying a list, details, and full-screen covers.
During the event, this project was chosen as the winner of the challenge.

## Video Demo

[![Watch the app demo](https://img.youtube.com/vi/mSgj3Gf6RXc/0.jpg)](https://www.youtube.com/watch?v=mSgj3Gf6RXc)


## Brief Description of the APP

Android application that connects to a server and retrieves images and descriptions of magazines. It includes some animations between activity transitions.
